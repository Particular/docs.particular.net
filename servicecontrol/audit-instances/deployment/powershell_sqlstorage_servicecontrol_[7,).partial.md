To use [SQL Server](/servicecontrol/storage/sqlserver/) or [PostgreSQL](/servicecontrol/storage/postgresql/) storage, set `-StorageType` to `SQLServer` or `PostgreSQL` and pass `-DatabaseConnectionString` instead of `-DBPath` and `-DatabaseMaintenancePort`, which apply only to RavenDB. SQL-backed Audit instances also require [external message body storage](/servicecontrol/storage/external-body/), which `New-ServiceControlAuditInstance` does not configure. Add the [`ServiceControl.Audit/MessageBody` settings](/servicecontrol/audit-instances/configuration.md#storage) to the instance's configuration file before starting it. The following example uses the same database as the Error instance; the Audit instance's tables go in the `sc_audit` schema by default.
