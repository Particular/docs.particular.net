---
title: Deploying Audit instances using ServiceControl Management
reviewed: 2026-09-02
component: ServiceControl
---

include: portable-application-note

When using ServiceControl Management to [create a new ServiceControl instance](/servicecontrol/servicecontrol-instances/deployment/scmu.md), a connected ServiceControl Audit instance can be created at the same time. Do this by clicking **New** > **Error + Audit** > **Next**

If necessary, a new Audit instance can be created by clicking **New** > **Audit only** > **Next**.
