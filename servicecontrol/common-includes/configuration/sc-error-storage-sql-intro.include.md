SQL Server and PostgreSQL storage require a database connection and external storage for message bodies. The ServiceControl Management Utility configures SQL-backed Error instances to store message bodies on the file system, in the **MESSAGE BODY PATH**. The PowerShell module also supports Azure Blob Storage and Amazon S3. To change the store later, change the `ServiceControl/MessageBody/*` settings in the instance's configuration file, starting with [`ServiceControl/MessageBody/StorageType`](#storage-servicecontrolmessagebodystoragetype). Changing the store does not move existing message bodies; see [external message body storage](/servicecontrol/storage/external-body/).
