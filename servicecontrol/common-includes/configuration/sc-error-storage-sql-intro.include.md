SQL Server and PostgreSQL storage require a database connection and external storage for message bodies. The ServiceControl Management Utility and the PowerShell module configure SQL-backed Error instances to store message bodies on the file system, in `%ProgramData%\Particular\ServiceControl\<instance name>\MessageBodies`. To use a different folder, Azure Blob Storage, or Amazon S3, change the `ServiceControl/MessageBody` settings in the instance's configuration file.
