### ServiceBus/ErrorQueue

The name of the error queue to ingest messages from.

| Context | Name |
| --- | --- |
| **Environment variable** | `SERVICEBUS_ERRORQUEUE` |
| **App config key** | `ServiceBus/ErrorQueue` |
| **SCMU field** | `ERROR QUEUE NAME` |

| Type | Default value |
| --- | --- |
| string | `error` |
