### LicensingComponent/SqlServer/ConnectionString

Version: 5.4.0+

| Context | Name |
| --- | --- |

| **App config key** | `LicensingComponent/SqlServer/ConnectionString` |

| Type | Default value |
| --- | --- |
| string | obtained from ServiceControl |
