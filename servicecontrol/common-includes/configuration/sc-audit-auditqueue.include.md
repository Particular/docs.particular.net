### ServiceBus/AuditQueue

The name of the audit queue to ingest messages from.

| Context | Name |
| --- | --- |
| **Environment variable** | `SERVICEBUS_AUDITQUEUE` |
| **App config key** | `ServiceBus/AuditQueue` |
| **SCMU field** | `AUDIT QUEUE NAME` |

| Type | Default value |
| --- | --- |
| string | `audit` |
