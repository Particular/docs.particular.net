SQL Server and PostgreSQL storage require an existing database and external storage for message bodies. The ServiceControl Management Utility and the PowerShell module configure SQL-backed Audit instances to store message bodies on the file system, in `%ProgramData%\Particular\ServiceControl\<instance name>\MessageBodies`. To use a different folder, Azure Blob Storage, or Amazon S3, change the `ServiceControl.Audit/MessageBody` settings in the instance's configuration file. See [SQL Server storage](/servicecontrol/storage/sqlserver/) or [PostgreSQL storage](/servicecontrol/storage/postgresql/).
