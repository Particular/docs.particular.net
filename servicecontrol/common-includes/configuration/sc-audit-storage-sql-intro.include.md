SQL Server and PostgreSQL storage require an existing database and external storage for message bodies. The ServiceControl Management Utility configures SQL-backed Audit instances to store message bodies on the file system, in the **MESSAGE BODY PATH**. The PowerShell module also supports Azure Blob Storage and Amazon S3. To change the store later, change the `ServiceControl.Audit/MessageBody/*` settings in the instance's configuration file, starting with [`ServiceControl.Audit/MessageBody/StorageType`](#storage-servicecontrol-auditmessagebodystoragetype). Changing the store does not move existing message bodies; see [external message body storage](/servicecontrol/storage/external-body/). See [SQL Server storage](/servicecontrol/storage/sqlserver/) or [PostgreSQL storage](/servicecontrol/storage/postgresql/).
