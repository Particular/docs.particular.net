### ServiceControl/AllowMessageEditing

Set to `true` to enable message editing when retrying messages.

| Context | Name |
| --- | --- |
| **Environment variable** | `SERVICECONTROL_ALLOWMESSAGEEDITING` |
| **App config key** | `ServiceControl/AllowMessageEditing` |
| **SCMU field** | N/A |

| Type | Default value |
| --- | --- |
| bool | `false` |
