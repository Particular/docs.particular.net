### ServiceControl.Audit/Authentication.ValidateAudience

_Added in version 6.11.0_

| **App config key** | `ServiceControl.Audit/Authentication.ValidateAudience` |
| **SCMU field** | N/A |

| Type | Default value |
| --- | --- |
