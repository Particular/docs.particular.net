- Major versions are supported for a period of one year after the release of the next major version.
- Only the latest minor version of the current major version is supported. Support for a minor version ends when the next minor version is released.
- Only the latest minor version of a previous major version is supported.

For a list of supported ServiceControl versions, refer to [supported versions](supported-versions.md).

## End of life

A version that is not supported is end of life. The [supported versions](supported-versions.md) table shows these versions as "Unsupported".

- An end-of-life version gets no patch releases. This includes fixes for bugs and for security vulnerabilities.
- Fixes are released for supported versions only.
- Security advisories can list end-of-life versions as affected. The fix is an upgrade to a supported version.

To get fixes, upgrade to a supported version.
