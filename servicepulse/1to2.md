ServicePulse version 2 is compatible with version 1. To upgrade, install the new version. If ServicePulse is hosted in IIS, follow the [IIS upgrade instructions](/servicepulse/install-servicepulse-in-iis.md#upgrading-servicepulse-hosted-in-iis) instead.

## Prerequisites

To view audited messages in the [All Messages](/servicepulse/all-messages.md) area, use ServiceControl version 6.6 or later and deploy and configure [Audit instances](/servicecontrol/audit-instances/). Without Audit instances, All Messages only shows failed messages.

## Upgrade Steps

1. **Download the latest version**:
   Obtain the ServicePulse version 2 installer from the [official download page](https://particular.net/downloads).

2. **Install the new version**:
   Run the installer and follow the on-screen instructions to complete the installation.

3. **Verify the installation**:
   Open ServicePulse and confirm that it is running version 2. Check that all existing configurations and data are intact.
