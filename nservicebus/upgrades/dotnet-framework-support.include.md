NServiceBus 8 is the last major version that supports .NET Framework. NServiceBus 9 and later require .NET 8 or later.

Because there is no newer NServiceBus version to upgrade to on .NET Framework, [extended support](/nservicebus/upgrades/support-policy.md#extended-support) for NServiceBus 8 on .NET Framework 4.7.2 and later runs until April 16, 2031, instead of April 16, 2028. Extended support requires a support agreement with Particular Software.

NServiceBus 7 on .NET Framework follows the standard extended support dates.
